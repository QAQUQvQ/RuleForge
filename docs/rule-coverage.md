# 规则覆盖

## M3 当前覆盖（2026-10-15）

正式库仍无 M2/M3 人工审核及 Runtime 许可。以下是实现与隔离模拟审核验收的覆盖，不是正式执行授权。M1 皮甲保持独立可执行。

| 机制 | 实现与来源 | 明确边界 |
|---|---|---|
| 先攻、回合、预算 | m3-turns；原始元素 2230–2259 中的固定段落 | 先攻由 DM 确认；同值稳定顺序或显式顺序；附赠动作仅预算 |
| 普通移动 | 逐格消耗、有效速度、clear_cells | 显式选择项目 5 ft Chebyshev 约定；拒绝未知/占用格和未实现借机攻击 |
| 普通近战攻击 | 调用 M2 AC/attack/damage/apply_hp | 服务端装备、AC、HP、防御快照；不支持额外攻击/特殊武器/远程消耗 |
| Ready / ReactionWindow | m3-ready；原始元素 2252、2253、2341–2343 | 指定角色完成相邻移动触发普通近战；不支持准备法术/移动、Shield、Counterspell |
| 持续效果 | Ready 至准备者下一回合开始 | 相同效果不可叠加；精确拥有者边界；结束清理 |
| Blinded 等状态 | DM 备注及明确移除 | 不作为自动修正；相关自动攻击/移动拒绝 |
| HP=0 / 死亡 | 记录 M2 结果与 dm_required | 未自动执行死亡豁免、稳定或怪物死亡政策 |
| 持久化与审计 | SQLite v4、原子幂等、乐观锁、事件链、重放 | 历史重建不绕过新行动许可；不提供人物卡回写 |

尚未支持完整法术、职业升级、特殊怪物能力、Homebrew、多租户公网授权。参战者可有 PC/NPC/Monster 身份，当前自动计算仍只接纳 M2 已验证的一级 Fighter 快照。

## M2 历史覆盖（2026-10-13）

正式数据库：17 条 validated / review_required / reference_only 目录记录，0 条发布、0 条 M2 执行许可。原 M1 皮甲规则仍独立可执行。下表的“计算已实现”指代码及隔离测试通过，不表示正式目录已经审核。

| 模块 | 已实现范围 | 来源与执行边界 |
|---|---|---|
| 检索 | 精确 ID、关键词、类型、已登记别名；详情和完整来源定位 | 公共视图仅发布目录；候选需本地管理令牌；未登记中文翻译不会自动匹配 |
| Fighter v1 | 1 级 HP、熟练 +2、六维调整值、两项技能、Defense、固定初始装备 | PDF24；原文元素547–584的必要子集及567职业表；无种族/背景/升级自动生成 |
| 新装备 | Longsword、Handaxe、Explorer's Pack | PDF66、70；继承 M1+ Dagger、Leather、Chain shirt、Chain mail、Shield、Torch |
| 角色保存 | 创建、读取、编辑、稳定 ID/版本装备引用、原子写入与乐观锁 | 新角色必须通过所有目录与运行许可门禁；旧 Equipment 模型保留 |
| AC | 轻/中/重甲、负敏捷、中甲上限、盾牌、Defense | 装备定义 + PDF62–64，Defense为PDF24；基础数值和熟练/速度/隐匿后果分开返回 |
| 普通无甲 AC | 纯算术向量有测试，运行接口明确拒绝 | 当前真实 JSON 未找到普通无甲公式直接来源；不借用职业专属公式 |
| 骰子 | d4/6/8/10/12/20/100，NdS±整数，固定序列、注入 RNG、日志与预算 | 无 eval；表达式1–99颗，单次计算最多1000颗；固定序列长度必须恰好匹配 |
| 攻击 | 单次近战、投掷远程攻击；属性、熟练、Finesse、优势/劣势抵消、自然1/20 | PDF64–65、76、94–95；调用方确认距离、可见、无遮挡与近敌情况 |
| 伤害 | 基础骰、暴击只翻倍骰子、独立分量、非负下限、无条件类型免疫/抗性/易伤 | PDF96–98及203/257的防御概念；复杂条件性抗性和额外职业伤害不自动引入 |
| HP | 临时优先、最大值约束、0下限、溢出、受伤时已0HP、即死阈值提示 | PDF96–98；返回dm_or_m3_required，不提交死亡、稳定或怪物死亡结论 |
| 集成预览 | 角色→装备→AC→攻击→伤害→隔离HP→完整规则/来源追踪，可重复 | ResolutionPreview；目标数据为明确的DM输入，不修改真实角色HP或战斗事件 |
| SQLite v3 | v1/v2 无损升级；空M2表可回滚，有数据拒绝降级 | 原始证据、原审核记录和皮甲DSL保持不变 |

明确未实现：完整回合、先攻、反应、行动经济、状态自动执行、法术攻击、弹药管理、双手/重型/触及/特殊武器机制、额外攻击、Second Wind 自动施放、多职业、死亡豁免状态机、Homebrew 与公网权限。仅登记武器和对应模板允许进入运行层；定义有字段不等于对应机制已启用。

模板数值约定、实际测试和正式/演示区别见 [M2 报告](m2-implementation-report.md)。以下为保留的 **M1+ 历史覆盖快照**。
